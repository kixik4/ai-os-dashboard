Zásady ochrany soukromí – AI OS Dashboard

Platné od 6. 11. 2026. Zpět na domovskou stránku

Kdo nástroj provozuje

AI OS Dashboard je soukromý osobní nástroj, který provozuje Michal Kica (kontakt: michal@kica.cz) na vlastním serveru. Používá ho jen on, nikomu dalšímu se nenabízí.

Jaká data z Google účtu nástroj používá

  • Google Kalendář (oprávnění calendar): čtení událostí kalendářů účtu michal.kica@gmail.com a vytvoření nové události jen tehdy, když ji Michal výslovně potvrdí.
  • Gmail (oprávnění gmail.readonly): pouze čtení zpráv. Nástroj nic neodesílá, nemaže, nepřesouvá ani neoznačuje.
  • Základní údaje o účtu (e-mailová adresa) pro rozpoznání, který účet je připojený.

Jak se data používají

Data slouží výhradně k tomu, aby Michal viděl svůj rozvrh a přehled pošty a mohl si naplánovat den. Nepoužívají se k reklamě, profilování ani k trénování obecných modelů umělé inteligence.

Kde se data ukládají

Přístupové tokeny a kopie událostí se ukládají jen na Michalově soukromém serveru, chráněném přihlášením. Server není veřejně dostupný.

Sdílení dat

Data se nikomu neprodávají ani nepředávají. Při zpracování požadavku, který Michal zadá, může být nutná část obsahu odeslána poskytovateli jazykového modelu, kterého si Michal sám zvolil. Jinak data server neopouštějí.

Omezené použití (Google API Services User Data Policy)

Použití a přenos informací získaných z Google API do jakékoli jiné aplikace se řídí zásadami Google API Services User Data Policy, včetně požadavků na omezené použití (Limited Use).

Uchování a smazání

Přístup lze kdykoli odvolat na myaccount.google.com/permissions. Po odvolání nástroj ztratí přístup a uložené tokeny přestanou platit. Kopie událostí se při další synchronizaci smažou nebo je provozovatel smaže na požádání.

Privacy Policy (English summary)

AI OS Dashboard is a private, single-user personal tool operated by Michal Kica (michal@kica.cz) on his own server. It uses Google Calendar (calendar: read events; create an event only on his explicit confirmation) and Gmail (gmail.readonly: read-only; never sends, deletes or modifies mail) solely to show him his schedule and mail overview. Data is stored only on his private, login-protected server, is never sold or shared, and is not used for advertising or to train general AI models. Content may be sent to a language model provider chosen by him only to process his own requests. AI OS Dashboard's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
